## 1. 需求背景与核心设计原则

### 1.1 用户实际画像
- **主要场景**：追某几位特定 B 站 UP 主（如护肤成分党、科技数码、深度长谈），单视频 3~22 分钟中文独白。
- **痛点诉求**：
  1. **算得清**：仅有 DeepSeek 额度，每花一分钱都要先看清楚，随时可能根据厂商调价（如按量打折、高峰期差异）微调单价。
  2. **听得到**：转写和问答带有时间戳，但核实 UP 主原声时需要额外跳到原网页，割裂严重。
  3. **看得爽**：思维导图节点展开后右栏空间局促；转写排版需舒适；全站状态流转需透明。

### 1.2 核心设计原则
1. **成本可知可控**：任何调模型的动作，点之前看到金额，单价随时可在前端自定义调整。
2. **零阻碍对齐**：时间戳从“标记文字”升级为“音文联动锚点”，点击即定位。
3. **视觉克制统一**：延续现有的冷灰底色 + 玫红强调色（B站风格），避免花哨无用的动效。

## 2. 设置页：模型单价手动配置与成本模拟（新增核心功能）

目前设置页为纯只读展示，提示用户手动修改 `config.yaml`。本模块将其升级为**支持在线编辑与即时生效的单价管理中心**。

### 2.1 功能设计
1. **价格可直接编辑保存**：
   - 输入 Token 单价（`price_input_per_m`，元/百万 token）。
   - 输出 Token 单价（`price_output_per_m`，元/百万 token）。
   - 货币符号（默认为 `¥`，可选 `$`）。
2. **预设快捷模板一键填入**：
   - `[DeepSeek V3 官方]`：输入 ¥2.0 / 输出 ¥3.0（百万 token）。
   - `[DeepSeek 缓存命中优惠]`：输入 ¥0.5 / 输出 ¥3.0。
   - `[通义千问 Qwen-Plus]`：输入 ¥0.8 / 输出 ¥2.0。
   - `[恢复默认]` 或 `[清空（仅显示 Token 数，不折算金额）]`。
3. **实时单价与成本模拟计算器（卡片内联）**：
   - 提供一个直观的“视频时长对照表”小面板：
     - 5 分钟（约 1,000 token）：约 ¥0.005
     - 15 分钟（约 3,000 token）：约 ¥0.015
     - 30 分钟（约 6,000 token）：约 ¥0.030
   - 用户调整单价时，模拟花费实时动态联动，改完心里有数。
4. **API 连通性快速测试**：
   - 在价格表单旁提供一个「测试 API 连接」按钮。
   - 点击后后端向配置的模型发送极小测试请求（约 3 token），返回 HTTP 延迟与成功状态，避免跑任务时才发现密钥过期或网络不通。

### 2.2 界面原型与交互流程

```
┌──────────────────────────────────────────────────────────┐
│ 设置 / 模型计费与价格换算                                    │
├──────────────────────────────────────────────────────────┤
│ 当前生效模型: deepseek-chat (OpenAI 兼容接口)             │
│                                                          │
│ 快捷预设: [DeepSeek 标准] [DeepSeek 缓存优惠] [清空不换算]     │
│                                                          │
│ 货币符号: [ ¥  ▼ ]                                        │
│ 每百万输入 Token 单价: [ 2.0  ] 元/M Tokens                │
│ 每百万输出 Token 单价: [ 3.0  ] 元/M Tokens                │
│                                                          │
│ ┌─ 实时成本参考 ──────────────────────────────────────┐  │
│ │ 中文独白按 ~3.2 token/秒估算:                        │  │
│ │ 10 分钟视频转写 ~2k tokens  -> 预计总结花费: ¥0.010    │  │
│ │ 20 分钟视频转写 ~4k tokens  -> 预计总结花费: ¥0.019    │  │
│ └─────────────────────────────────────────────────────┘  │
│                                                          │
│ [ 保存配置 ]   [ 测试 API 连通性 ] (延迟: 420ms · 正常)   │
└──────────────────────────────────────────────────────────┘
```

## 3. 详情页：本地音频原声对齐与双栏交互升级

### 3.1 本地音频原声对齐播放器（Audio Player Bar）
- **核心逻辑**：
  - ASR 流程执行后，音频已保存在 `output/<标题-ID>/audio/` 中。
  - 后端提供静态或流式音频路由：`GET /api/videos/{video_id}/audio`。
- **界面与交互**：
  - 在详情页底部常驻一个**极简纤细音频条**（或者内嵌于左栏顶部）：
    - 控件：播放/暂停、进度条、当前时间/总时长、倍速按钮（`1.0x` / `1.25x` / `1.5x` / `2.0x`）。
  - **点击段落联动**：
    - 点击左侧转写任意段落段首的时间码（如 `03:27`），音频立即 seek 到该秒数并开始播放；
    - 点击“问视频”回答中的任何时间戳徽章（如 `[04:12]`），音频同步定位播放；
  - **跟随高亮**：音频播放时，左侧对应时间区间的段落获得轻度柔和高亮，并可选开启“随音频自动滚屏”。

### 3.2 左右双栏交互增强（Resizable Split Pane）
- **拖拽调节栏宽**：
  - 左右分栏中间的分割线支持鼠标拖拽（Cursor: `col-resize`），允许用户将导图栏拉大至 70% 宽，或将转写栏拉大至 70% 宽；
  - 本地记住用户的分栏比例偏好（`localStorage`）。
- **思维导图「全屏 / 展开模式」**：
  - 导图操作栏目前已有“居中”和“下载 SVG”；
  - 增加 **「全屏模式」** 按钮：点击后思维导图铺满整个视窗，方便对复杂思维导图（100+ 节点、4+ 层）进行大画幅缩放浏览；按 `ESC` 退出。
- **导图大纲与总结的多格式复制导出**：
  - 思维导图增加一键「复制大纲文本（Markdown）」按钮，便于无缝粘贴进 Obsidian、Notion、XMind；
  - 转写文本增加「导出纯文本 / 导出 SRT 字幕」选项。

## 4. 全局与侧边栏：常驻任务队列与进度指示

### 4.1 痛点
用户在新任务页提交批量任务（或单个大视频）后，切换到「库」或「视频详情」进行阅读时，完全脱离了任务进度视野，不知道后台是否还在跑、是否报错。

### 4.2 解决方案：Mini Queue Indicator
- 在侧边栏（`Sidebar.tsx`）底部或全局顶部导航区嵌入**迷你状态胶囊**：
  - **空闲时**：隐藏或显示静默小点。
  - **有任务在跑时**：
    ```
    [⟳ 语音识别 64%] 视频标题... (队列 2 项)
    ```
  - 点击胶囊：直接弹出一个轻量 Drawer（或快速跳转至 `/` 并定位到运行任务）。
  - **任务完成提示**：任务结束后右下角弹出轻量 Toast（“《某视频》转写与总结已就绪”），点击直达详情页。

## 5. 库页面：UP 主分组管理与多维排序

### 5.1 UP 主分组折叠与管理
- 当同一 UP 主视频较多时，默认平铺导致页面滚动过长。
- **改进**：
  - 每个 UP 主的分组卡片标题栏增加折叠箭头（`▾ / ▸`），支持单个折叠或一键全部折叠；
  - 支持“只看该 UP 主”后显示更密集的网格或表格视图。

### 5.2 列表排序能力
- 在库页面搜索栏右侧增加排序下拉控件：
  1. **按处理时间**（默认）：最新转写的在最前。
  2. **按发布日期**：看博主的历史时间线。
  3. **按时长**：挑短视频先看，或找深度长视频。
  4. **按累计花费**：一目了然看哪条调大模型最贵。

## 6. 新任务与批量页：轻量追更与体验微调

### 6.1 UP 主一键追更
- 侧边栏的 UP 主列表项增加悬停动作图标：**「检查更新」**。
- 点击后前端直接调用 `probe(up_space_url, page=1)`，对比本地库已有的 `video_id`：
  - 若无新视频，轻量 Toast 提示“已是最新投稿”；
  - 若有新视频，直接弹出勾选抽屉，勾选后一键排队入队。

## 7. 后端配套接口改造建议

为支持上述 UI 改进，后端建议配套补充以下轻量级接口（全部遵循 FastAPI 原生规范）：

| 方法 | 路径 | 作用 | 说明 |
|---|---|---|---|
| `GET` | `/api/config/pricing` | 获取当前生效单价与货币 | 返回 `{price_input_per_m, price_output_per_m, currency}` |
| `POST` | `/api/config/pricing` | 在线更新单价配置 | 验证数值后写回 `config.yaml` 或持久化存储，无需重启 |
| `POST` | `/api/config/test-llm` | 测试大模型连通性与耗时 | 发送简单 ping 提示词，返回 `{ok: bool, latency_ms: int, error?: str}` |
| `GET` | `/api/videos/{id}/audio` | 获取该视频的本地音频文件 | `FileResponse(audio_path)`，支持 HTTP Range（快进快退） |

## 8. 分期实施建议（Roadmap）

建议分 3 个小迭代有序推进，每次迭代独立自洽：

### 阶段一：设置页价格管理与单价动态换算（高优先级，立即可行）
- [ ] 后端新增 `/api/config/pricing` 读写接口；
- [ ] 前端 `Settings.tsx` 增加“价格换算与单价自定义”表单与快速预设；
- [ ] 全站计费展示动态关联新单价；
- [ ] 增加 API 快速连通性测试。

### 阶段二：详情页音频对齐播放与导图全屏/分栏拖拽
- [ ] 后端暴露 `/api/videos/{id}/audio` 音频文件访问路由（带 Range 请求支持）；
- [ ] 详情页加入极简音频控制条，实现时间戳点击定位播放；
- [ ] 详情页左右分栏增加 Resizable 拖拽把手；
- [ ] 思维导图加入全屏预览与 Markdown 大纲快速复制。

### 阶段三：全局队列 Mini 状态与库管理优化
- [ ] 侧边栏增加任务队列实时迷你状态条与 Toast 提醒；
- [ ] 库页面增加 UP 主折叠分组与多维排序（时长/日期/花费）；
- [ ] 侧边栏 UP 主增加一键空间追更新检查。
