我这老头子都要做精致的猪猪男孩，希望大家今天能学到不少干货。最近我又发现了一个美妆小心得，给大家推荐一个便宜好用的东西，男生也可以用，男女都可以用。冬天大家脸不是会干嘛？等再冷一点，屋里面开空调、有地暖了，整个人就更干了。我之前跟你们说过，男生护肤不用太复杂，简单喷个水就行了。喷雾补水，你要买那种喷头细的，小分子这样补的话比较能够进去。像那种水呀、乳液呀，其实我觉得很难进去。

02:13

任何很贵的面霜、贵妇化妆品都不要去花那个冤枉钱，给我买十几二十块钱的甘油就行。这个甘油买了往脸上擦，给它揉进去，只要四五滴。维E保湿护肤甘油，一般来说搜"护肤甘油"就会跳出来。我买的是伊美雅这个牌子，二十几块钱一大罐，可以用好久。滴几滴在手掌然后抹到脸上，你明显感觉水能锁住了。我的脸又出油又掉皮是什么情况？严重的水油不平衡。最简单的：洗脸一天洗一回，晚上洗早上不洗。洗面奶一天就只能用一回，哪怕你油到爆了。

04:25

然后有个万能的东西叫冰箱里的芦荟胶。芦荟胶起到镇静作用，你的脸之前太干了、补那么多东西可能负担过大，拿冰箱里的芦荟胶敷脸上敷一层，让它冰一冰，可以收缩一下毛孔又可以镇静。冬天有刺痛感是很正常的事情。我今天主要就是跟大家说甘油这个东西，大家也可以不用去买那种专门的男士护肤品或者很贵的护肤品，都没用，这是我的血泪教训，反正都已经帮你们试过了。男孩子的护肤其实都一样。男士护肤品有一些以清爽主打，洗完脸干得不行。

06:36

要用喷雾，不要用水，也不要用精华跟面霜了，冬天用那个东西没用。除非你已经买好了有面霜，就照我说的，先涂面霜，厚敷在你起皮、特别干的地方，鼻翼、脸颊、嘴角，厚敷一层擦掉，然后就只用喷雾跟甘油就可以了，别的东西都可以不花这个钱。我这个年纪还在冒痘怎么办？每个月都冒痘的话直接去皮肤科医院，不要去做挑痘，医生会给你配药膏，几毛钱涂一涂就好了。挑痘解决不了问题，而且痘痘永远不要挑。

冬天我觉得男生没有必要刷酸。补水喷雾买啥牌子？颐莲，我帮你们测试过了，这个喷雾特别细，喷出来是雾不是水。雅漾那个喷雾喷出来跟喷泉似的。你们现在是觉得水、精华、面霜这一套流程是不是冬天就不干了？妮老师告诉你们只有两个流程：喷水、涂甘油，没有了。就是告诉大家如何用最具性价比的东西去保养好自己的皮肤，因为你东西涂过多了也会过剩，吸收不进去的都被浪费掉了。这两样东西加起来也很便宜，双十一买几大罐几十块、一百块左右。

冬天男生护肤只要两步：喷细雾喷雾，再涂十几块钱的护肤甘油。水精华面霜那一套涂多了吸收不进去，是浪费；贵妇品、男士专用品都没用。

核心观点

  • 关键在锁水，不在补水。又出油又掉皮是水油不平衡，补进去锁不住才是问题。
  • 两样东西，单价都不过五十块。颐莲喷雾（喷头细，出来是雾不是水）+ 任意牌子的维E保湿甘油（她买的伊美雅，二十几块一大罐）。
  • 洗面奶一天只能用一回。早上清水泼脸、洗脸巾按干；哪怕油到爆也不要多洗，洗多了破坏角质层。

流程

  • 早上：清水洗脸 → 喷一层喷雾，半干时手掌摁进去（不要拍）→ 再喷一层再摁 → 四五滴甘油揉开 → 出门前防晒棒。
  • 晚上：洗澡时先用洗面奶洗脸 → 特别干的地方厚涂维E或大宝，半干时擦掉 → 喷雾两遍 → 甘油。

问题肌肤

  • 冒痘：每月都冒去皮肤科开几毛钱药膏，不要挑痘。
  • 黑头：一周一次温和泥膜敷鼻子二十分钟，擦掉后厚涂芦荟胶。
  • 嘴角脱皮：金霉素眼膏厚涂过夜。黑眼圈：本质是淤青，涂活血化瘀药膏，眼霜没用。

避坑

  • 功能性面膜养不进去，一周顶多两次；冬天不要刷酸；男士洗面奶洗完脸干巴；美容店小气泡、挑痘一百多块没用。
  • 防晒冬夏都要，紫外线晒斑、晒干、长皱纹，不防晒等于白护。
